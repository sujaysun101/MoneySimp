# **App Name**: PennyWise

## Core Features:

- Manual Expense Tracking: Allow users to input and categorize their expenses manually.
- Bill Scanning: Enable users to upload photos of bills; app parses information using OCR to extract relevant expense data.
- Budget Setting: Enable users to set monthly budgets for different categories (e.g., groceries, rent) and track their spending against these budgets.
- Monthly Insights: Present spending data through charts and graphs (bar, pie) for easy understanding of spending patterns. Also show category breakdowns and trends over time.
- AI Finance Tips: Provide daily AI-generated personal finance tips. The AI tool personalizes advice based on the user's spending habits.

## Style Guidelines:

- Primary color: Teal (#4DB6AC) for a sense of financial stability and calm.
- Background color: Light grey (#F0F4F3) for a clean and modern look.
- Accent color: Warm orange (#FFB74D) to highlight key data points and CTAs.
- Clean, sans-serif fonts optimized for readability in data-heavy interfaces.
- Use minimalist icons to represent expense categories, ensuring clarity and ease of use.
- Prioritize a clean, data-centric layout with clear hierarchy to avoid overwhelming users.
- Subtle animations on data updates and transitions to provide feedback and enhance the user experience.
